# Prabhat Chauhan — Portfolio (GitHub Pages)

Video Editor portfolio website. Live demo ke liye GitHub Pages pe deploy karo.

## GitHub Pages pe live karne ke steps (5 min, git nahi chahiye)

1. **GitHub account banao** (agar nahi hai): https://github.com/signup
2. **Naya repo banao**: https://github.com/new
   - Repository name: `prabhatchauhan.github.io` (agar yeh username tumhara hai)
     — ya koi bhi naam, e.g. `portfolio`
   - Public rakho, "Add a README file" tick karo
   - **Create repository** dabao
3. **Files upload karo**:
   - Repo page pe **Add file → Upload files** dabao
   - Is folder ki saari files/folders (`index.html`, `assets/`, `.nojekyll`) drag-and-drop karo
   - Neeche **Commit changes** dabao
4. **Pages enable karo**:
   - Repo me **Settings → Pages** (left sidebar)
   - Source: **Deploy from a branch** → Branch: **main** → **Save**
5. **1–2 min wait karo** — site live hogi:
   - `https://<tumhara-username>.github.io/` (agar repo ka naam `prabhatchauhan.github.io` hai)
   - ya `https://<tumhara-username>.github.io/portfolio/` (agar repo ka naam `portfolio` hai)

## Files

- `index.html` — poori website (single file)
- `assets/` — videos (.mp4) + posters (.jpg)
- `.nojekyll` — GitHub Pages ko batata hai files ko as-is serve kare

## Update kaise kare

Koi video/text badalna ho to file replace karke dobara **Add file → Upload files** se upload kar do — site auto-update ho jayegi.
